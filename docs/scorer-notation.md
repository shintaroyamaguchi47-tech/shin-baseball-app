# スコアラー(GDF)スコアブック記譜法 — 解読メモ

本アプリの「📖 スコアブックPDF」を、スコアラーアプリが出力する伝統的スコアブック様式に
一致させるための、記号体系の解読メモ。3試合の「PDF画像 + 同一試合のGDF(.txt)」ペアを
突き合わせて解読した（駿河セントラル戦=gid423, 東戦=gid421, 竜爪西奈戦=gid419）。

confidence: ◎=データで確認済 / ○=ほぼ確実 / △=推測(要検証)

**公式凡例**: https://bbscorer.com/help/score_basic.html で下記の多くを確認済み。
- 投球: ●ボール ◎見逃し ○空振り －ファウル ◇バント空/ファウル
- 中央: ●得点(自責) ○得点(非自責) ℓ残塁 ─打順スキップ / Ⅰ Ⅱ Ⅲ アウト
- 三振: K見逃し Ks空振り K*バント / 振り逃げ K→e(失敗) K+WP・K+PB(成功)

## 1マス(1打席)のレイアウト

```
┌──────────────┐
│●             │  ← 左端: 投球マーク列(1球=1マーク, 上→下)
│●   Sᵃ        │  ← ダイヤ上・右corner: 進塁の理由ラベル(+リンク文字)
│◎  ／◇＼      │
│●  ◇ ℓ ◇  ← 中央: 走者の状態
│●   ＼◇／     │
│    B    5-3  │  ← ダイヤ下: 到達理由 / 右下青字: 守備結果
└──────────────┘
```

### 十字の4区画=各塁 ◎
十字線で仕切られた4区画はそれぞれの塁に対応する(右下=一塁, 右上=二塁,
左上=三塁, 左下=本塁)。**打席結果は打者自身が到達した塁の区画に書く**:
アウト・単打・出塁=右下 / 二塁打=右上 / 三塁打=左上 / 本塁打=左下。
走者としての進塁(何番打者で進んだか・S/WP/PB等)も到達塁の区画に書く。

### 中断打席 ◎
打席の途中で走者アウト(盗塁死等)により3アウトが成立した場合、打席は完了
しない。投球マークだけを残し、結果表記・アウト採番・打席数は付けない
(実例: gid417系 2回裏、2ボール1ストライクから1塁走者盗塁死でチェンジ)。

## 投球マーク列(左端, 上から下へ1球ずつ) ◎

スコアラーは **● = ボール**、ストライク系は輪で描く（一般的な慣習と逆）。

| GDF | 意味 | マーク |
|---|---|---|
| Pb | ボール | ● 黒丸 |
| Pl | 見逃しストライク | ◎ 二重丸(bullseye) |
| Ps | 空振りストライク | ○ 白丸(△空振りは別形かも) |
| Pf | ファウル | ○ 白丸(△要検証) |
| Db | 死球 | (打席内に含む) |
| Rq | 牽制 | (投球マーク列には出さない) |

根拠: 植松 1回(Pb Pb Pl Pb Pb=四球) → ●●◎●● と表示。●が4つ=4ボール、◎が見逃し1つ。

## ダイヤモンド(走者の進塁)

- 四隅 = 塁。**下=本塁, 右=一塁, 上=二塁, 左=三塁**。
- **黄色い三角**(隅の内側) = 走者が到達した塁（最終到達塁を黄で示す）。○
- 本→一, 一→二, 二→三, 三→本 の各辺 = 進塁した区間。走者が進むと辺が描かれる。○
- **中央 ● 黒丸** = 生還(得点)。◎
- **中央 ○ 白丸** = 出塁したが残塁(LOB)。◎
- ダイヤが空 = 出塁せず(打者アウト)。○
- **ローマ数字 Ⅰ/Ⅱ/Ⅲ**(ダイヤ中央) = イニングで何アウト目か。◎
- **赤い斜線**(辺を横切る) = その塁間で走塁死/タッチアウト。◎
- **ℓ (筆記体)** = 出塁した走者の到達マーク(△: 打者が塁に生きた印と思われる)。
- グレー三角(下) = △要検証。

### 隅の理由ラベル(どうやってその塁へ進んだか)
| ラベル | 意味 |
|---|---|
| B | 四球(base on balls) ◎ |
| S | 盗塁(steal) + 上付きリンク文字 ◎ |
| WP | 暴投(wild pitch) ◎ |
| PB | 捕逸(passed ball) ◎ |
| HBP / DIB | 死球 / 打撃妨害 ○ |
| H | 安打(打者自身の到達) △ |

### 上付きの a b c d e (マゼンタ) ◎
進塁が「何番目の事象で起きたか」を、左の投球マーク列の該当位置と結ぶ連番。

## 守備結果(ダイヤ右下・青字)

| 表記 | 意味 |
|---|---|
| Ks | 空振り三振(K + swinging) ◎ |
| K | 見逃し三振(△: 最終球が見逃しのKo) |
| 5-3 / 6-3 / 4-3 / 1-3 | ゴロ→送球アウトの守備経路(数字=守備位置) ◎ |
| 数字にアーチ ⌢ (例 ⌢6 ⌢7 ⌢2) | 飛球を捕球しアウト(6=遊飛, 7=左飛, 2=捕飛) ◎ |
| 数字に直線 ─ | ライナーを捕球しアウト(公式凡例で確認) ◎ |
| F+数字にアーチ (例 F3) | ファウルフライ(3=一塁)(公式凡例で確認) ◎ |
| 四角枠 | 犠打・犠飛(公式凡例で確認) ◎ |
| 数字+Ef / Es | 失策(fielding/送球エラー) ○ |
| 6Et-3 | 遊撃→送球エラー→一塁 等の複合 △ |
| 先頭◇ | インプレー打球の方向印(△) |

### 守備経路の実データ(Th=送球先) ◎
cdコードの `Th{n}`(n=0投〜8右)は捕球後の送球先。打球位置(`-{zc}`)の野手と
連結すると実際の守備経路になる(2026-07-14に9試合の実データで検証):
- `Go--54Th2O01` = 遊ゴロ→一塁送球 → **6-3**
- `Go--23Th0O01` = 一ゴロ→投手ベースカバー → **3-1**
- `Go--54Th3O12` = 遊ゴロ→二塁封殺(打者は生きる=Fc) → 6-4
- `Go--20...O01`(Th無しor自塁) = 一塁手自力 → **3**
- `Tb{n}` は送球元(盗塁死 `RfTb1Th5T12` = 捕→遊 2-6)。経路には使わない

## 括弧数字 (n) [n] △要検証
ダイヤの隅に現れる (2)(3)(4)や[4]。走者が進塁/アウトになった時点の
アウトカウントや打順、または投球数の可能性。未確定。次の反復で詰める。
